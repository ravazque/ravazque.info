# Security policy

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/ravazque/ravazque.info/security/advisories/new), never in a
public issue. Include the affected page or endpoint, the steps to reproduce and the impact.

In scope: the web app (`server/`, `web/`) and its Docker and Caddy configuration. The CV site has its own repository,
[ravazque.github.io](https://github.com/ravazque/ravazque.github.io).
Out of scope: the 42 API and intra themselves, and denial of service through volume.
